# RightNote

> One named RightNote notebook. Finish the page. Leave a note the next writing desk can read.

## Session Card

| Slice | What you do in RightNote | What remains |
|-------|------------------------|--------------|
| Notebook | Open RightNote and name today's writing desk | A titled notebook set |
| Page | Keep only live pages on the RightNote board | A short tree list |
| Quick | Read RightNote quick notes before a long draft | A confirmed page set |
| Handoff | Mark finished pages inside RightNote | A note for the next visit |

## How RightNote Sits

RightNote does not replace the word processor, the mail draft, or the paper notebook you already keep. It sits beside them as a named writing desk for one job: which notebooks are live, which tree pages still match the quick notes, and what the next person should read before the next page.

A first visit should be one short page, then the same RightNote writing desk the next day. That is enough to see if the notebook tree holds.

## Traffic Light

| Signal | On the RightNote board | What you do |
|--------|----------------------|-------------|
| Green | Named desk, short live page list | Continue the same notebook |
| Amber | Two drafts mixed in one tree | Split the pages before you write |
| Red | No title, no note, pages untitled | Stop and name the notebook first |
| Clear | Handoff written, live pages few | Close RightNote and leave the desk |

## Open Order

1. Open the last RightNote writing desk, not a new empty notebook.
2. Read the tree pages and the last handoff.
3. Finish one visible quick note inside RightNote.
4. Write what changed, then close with fewer untitled pages than you found.
5. If the tree feels crowded, drop anything that belongs to a different RightNote notebook.
6. Confirm RightNote notebooks still hold the sections you named.

## After a Week

A week in RightNote is not a larger endless file. It is the same title, a shorter live page tree, and a note that still makes sense before the next draft. Take finished pages off the live set so the next visit starts on the notebook that is still open.

Other programs stay where they are. RightNote only keeps the path back: desk name, notebooks, tree pages, handoff.

## Sign-off

- [ ] The RightNote workspace name is short enough to scan
- [ ] Only live pages sit on the tree
- [ ] A second person can read the notebook handoff
- [ ] The last RightNote notebook still opens after a restart
- [ ] Finished pages are off the live RightNote set

## Field Note

RightNote is easier to trust when the writing desk stays smaller than the endless file it came from. Name the notebook, keep the live pages, finish one visible quick note, and write what changed.

The same loop fits a draft week, a study notebook, or a shared computer. Open the last RightNote desk and continue. Do not rebuild the tree from scratch.
